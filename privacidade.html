Política de Privacidade

Última atualização: 12 de novembro de 2026.

Quem somos

Canal Histórias é um canal de vídeos curtos. Usamos uma ferramenta interna, de uso exclusivo do canal, para enviar nossos próprios vídeos ao YouTube, TikTok e Instagram.

Dados acessados

A ferramenta acessa somente as contas do próprio canal, por meio das APIs oficiais (YouTube Data API, TikTok Content Posting API e Instagram Graph API), com as permissões necessárias para publicar vídeos e ler informações básicas do perfil. Não coletamos dados de outros usuários ou espectadores.

Uso dos dados

Os dados e tokens de acesso são usados apenas para publicar os vídeos do canal. Não vendemos, compartilhamos ou usamos esses dados para outra finalidade.

Armazenamento e segurança

Os tokens ficam guardados como segredos criptografados no ambiente de automação do canal e podem ser revogados a qualquer momento nas configurações de cada plataforma.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
